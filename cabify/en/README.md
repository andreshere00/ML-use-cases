# Cabify: legitimate or artificial traffic with binary classification

Standalone Slidev deck for the **Cabify** use case, part of the InnoIT *Machine learning in real companies* series. The complete series lives in [`../../general/en`](../../general/en). The Spanish version is in [`../es`](../es).

## Contents

- `slides.md`: the deck (cover, the problem, case, interactive solution, discussion).
- `theme/`, `public/`, `data/`, `diagrams.json`: InnoIT theme, fonts, synthetic data and diagram content.
- `tools/`: scripts that build the interactive explorer and regenerate its synthetic data.
- `CABIFY-EXPLORER.md`: controls, computation details and limits.
- `cabify-traffic.html` is the standalone offline explorer, regenerated by `pnpm build:explorer`.

## Run

Requires Node.js 22.12+ and pnpm.

```bash
pnpm install
pnpm dev      # live deck
pnpm build    # explorer + static web version in dist/
pnpm export   # PDF
```
